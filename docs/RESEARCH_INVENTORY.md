## Initial feature/source matrix

| Capability | Projects with listing evidence | Integration question before reuse |
|---|---|---|
| Summons, portals, requests and provider listings | Odd Jobs, Voidtaxi, Wormhole, Leyline, Mage Dash, Portaxi, Summon Board, Biquette Taxi Portal, Uber Azeroth, ForeverTaxi, ForeverPortaxi, Taxi Ride LindaLuna, Summon Circle | Multiple protocols and distinct scopes; map permissions, payload formats, instance behavior and server restrictions before selecting a unified transport. |
| Public chat scanning | Odd Jobs, LFS Forever, Biquette Taxi Portal, ForeverPortaxi, Taxi Ride LindaLuna, Mana’s Portal Service, BetterPortalForever; possibly other packages | Must be opt-in, source-labeled, local-only by default and reviewed for chat event/API semantics; do not rebroadcast or automate messages by assumption. |
| Cross-layer or broader discovery claims | Odd Jobs, Azeroth Message Board, LFS Forever, Layercake, CraftBoard, ForeverTaxi, others | “Global” is not interchangeable: hidden channels, guild/group channels, relays and dedicated named channels have different reach and restrictions. Validate in source and client. |
| Crafting directory and orders | Odd Jobs, LFS Forever, Azeroth Message Board, CraftBoard, TalentShare/Guild ProfessionShare, Guild Profession Directory, Trueque | Recipe data may depend on opening trade-skill windows, language, schema/version and guild peer presence. Preserve each SavedVariables schema during migration. |
| Ratings / transaction trust | Portaxi, some travel services | Only verified mutually confirmed transactions should influence ratings; reports and personal notes stay separate. Inspect validation and anti-abuse rules. |
| Provider queue / operational tools | Wormhole, Leyline, Portaxi, Summon Circle, Mana’s Portal Service, BetterPortalForever | Keep invites, whispers, casts, trades, advertisements and acknowledgements behind explicit user action for WildHelp’s default design. |

## Initial conflict and migration notes

- Repeated slash commands already conflict in source list: `/taxi` is used by ForeverTaxi and Taxi Ride LindaLuna; `/ptx` is used by Portaxi and ForeverPortaxi. WildHelp reserves `/wh` and `/wildhelp`.
- Several projects have standalone channel handlers, chat scanners, queue engines and recipe databases. Do not load these unchanged beside a new shared service layer without source-level namespace and protocol review.
- Preserve data by exporting or explicitly migrating each SavedVariables table after source inspection. WildHelp's alpha currently has only `WildHelpDB`; no legacy database is deleted or rewritten.
- All Rights Reserved pages are not open-source grants. The user's stated author permissions are authorization context, but permission evidence and per-file source attribution still need to be recorded before copying those files.
